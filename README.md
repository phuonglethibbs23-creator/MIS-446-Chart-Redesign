# MIS 446 – Data Visualization Critique and Redesign

## Project Overview
This project evaluates an existing chart presenting death rates among White Virginia residents and redesigns the visualization to improve clarity and readability.

## Objectives
- Identify weaknesses in the original data visualization.
- Reconstruct the original chart using Microsoft Excel.
- Develop an improved visualization for more effective data comparison.
- Communicate data accurately through appropriate chart design.

## Dataset
The analysis compares four population groups:
- Urban Female
- Urban Male
- Rural Female
- Rural Male

The data covers age groups from 50–54 to 70–74, with death rates measured per 1,000 population.

## Tools
- Microsoft Excel
- Microsoft Word
- Canva or PowerPoint (for presentation, if applicable)

## Visualization Improvements
The original chart was evaluated for unnecessary 3D effects, overlapping visual elements, and insufficient labeling.

A 2D clustered column chart was proposed to make comparisons across age groups and population categories easier to interpret.

## Project Deliverables
- Original chart critique
- Reconstructed chart
- Redesigned visualization
- Written report and presentation materials

## Key Learning Outcomes
- Evaluating data visualization effectiveness
- Selecting appropriate chart types
- Improving chart readability and data comparison
- Communicating analytical findings clearly
